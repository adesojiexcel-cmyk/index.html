EXCEL BAKES & TREATS WEBSITE

FILES
- index.html: Home page
- about.html: About page
- services.html: Products and services page
- contact.html: Contact page
- style.css: Shared styling

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension.
4. The pages link to one another through the shared navigation bar and footer.

BOOTSTRAP COMPONENTS USED
- Responsive navbar (all pages)
- Product cards (home and services)
- Modal (services page)
- Responsive grid and form components

IMPORTANT
- An internet connection is needed for the Bootstrap CDN and online sample photos.
- Replace the sample phone number, email and location on contact.html with your own details.
- The contact form is a front-end demo only; it does not send emails.
